## Refactoring & Simplification 
 1. torch.cat in a loop inside infer_batch — O(n²) memory copies                          
                                                                                           
  The biggest offender. Every step allocates and copies the entire sequence:               
                                                                                           
  # session_transformer.py:625-627 — current
  cur_e = torch.cat([cur_e, a_idxs.unsqueeze(1)], dim=1)                                   
  cur_i = torch.cat([cur_i, i_idxs.unsqueeze(1)], dim=1)                                   
  cur_d = torch.cat([cur_d, bin_idxs.unsqueeze(1)], dim=1)                                 
                                                                                           
  Pre-allocate [B, max_steps] buffers and index into them. This is the standard pattern for
   autoregressive generation.
                                                                                           
  ---             
  2. Manual padding in two places that should use pad_sequence
                                                                                           
  collate_fn (dataset.py:276-286) and GRU4RecAdapter.fit (downstream.py:169-173) both do
  the same manual zero-fill loop. Both can be replaced with:                               
                  
  from torch.nn.utils.rnn import pad_sequence                                              
  padded = pad_sequence(tensors, batch_first=True)                                         
   
  ---                                                                                      
  3. Unnecessary .float() on bool mask in CrossSessionHistory
                                                                                           
  # session_transformer.py:156 — current
  key_padding_mask=key_padding_mask.float() if key_padding_mask is not None else None      
                  
  PyTorch's MultiheadAttention has accepted bool key_padding_mask directly since 1.9. The  
  .float() conversion is the old pre-1.9 workaround and may actually trigger deprecation
  warnings in current PyTorch.                                                             
                  
  ---
  4. ITEM_BEARING_IDX loop in infer_batch

  # session_transformer.py:584-586 — current
  is_item = torch.zeros(B, dtype=torch.bool, device=device)                                
  for idx in ITEM_BEARING_IDX:
      is_item |= (a_idxs == idx)                                                           
                                                                                           
  This is what torch.isin is for:
                                                                                           
  is_item = torch.isin(a_idxs, torch.tensor(list(ITEM_BEARING_IDX), device=device))
                                                                                           
  Same pattern appears in train.py:131-133.                                                
                                                                                           
  ---                                                                                      
  5. Jaccard diversity — O(n²) Python set loop
                                                                                           
  # reference.py:246-252 — current
  for i in range(n):                                                                       
      for j in range(i + 1, n):
          inter = len(item_sets[i] & item_sets[j])                                         
          union = len(item_sets[i] | item_sets[j])                                         
                                                                                           
  With 500 sessions this is 125K Python set operations. Binarize to a scipy sparse matrix  
  and use sklearn.metrics.pairwise_distances(X, metric='jaccard') — one vectorized call.
                                                                                           
  ---             
  6. CrossSessionHistory.encode — per-session loop in infer_batch
                                                                                           
  # session_transformer.py:528-535 — current
  memories = []                                                                            
  for _, _, _, history in batch_inputs:
      ...                                                                                  
      memories.append(mem)
  memory = torch.cat(memories, dim=0)                                                      
                                                                                           
  The histories could be batch-padded once and encoded in a single                         
  self.history.encode(hist_emb_batch, key_padding_mask_batch) call, eliminating the Python 
  loop. This is a non-trivial refactor but it's the correct batched pattern and removes the
   # This fucking sucks comment on line 526.
